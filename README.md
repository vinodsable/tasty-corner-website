# Tasty Corner - Restaurant Website

A responsive restaurant website built with HTML, CSS and JavaScript.

**Live Demo:** https://vinodsable.github.io/tasty-corner-website/

## Features
- Fully responsive (mobile, tablet, desktop)
- Sticky navbar with hamburger menu
- Menu cards, photo gallery, customer reviews
- WhatsApp order button and Google Maps embed
- Working contact form (Formspree)

## Built With
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript
